Key AI Approaches — In Plain Terms
🔍
RAG — Retrieval-Augmented Generation
Smart context injection before AI generation
Before asking the AI to generate test steps, the system searches your Salesforce metadata (stored as vectors) for the most relevant information — required fields, picklist values, validation rules, and past execution patterns. This context is injected into the prompt so the AI produces org-specific, accurate steps rather than generic ones.
OpenAI Embeddings Cosine Similarity Top-K Search
🔗
MCP — Model Context Protocol
AI ↔ Salesforce live data bridge
MCP is a standardised protocol that lets the AI model talk directly to Salesforce in real time. It enables the system to query live records, describe objects, run SOQL, and fetch lookup candidates at runtime. During Self-Healing, MCP fetches fresh field metadata so Claude can generate corrected test steps that work on the actual org.
simple-salesforce SOQL / SOSL Tooling API
🧬
Vector Database
Semantic memory for metadata
Salesforce object metadata (fields, types, picklists, validation rules, flows, LWCs) is converted into numeric vectors using OpenAI's embedding model and stored in PostgreSQL. When a tester describes a test, the system finds semantically similar metadata — not just keyword matches — enabling accurate, context-aware test generation.
PostgreSQL vectors text-embedding-3-small Chunked storage
🩺
AI Self-Healing
Tests that fix themselves after failure
When a test fails due to a Salesforce application error (missing required field, validation rule, modal overlay), the system automatically detects the failure pattern, fetches live field metadata via MCP, and calls Claude to generate a corrected set of steps. The QA can then apply or tweak the fix interactively.
Claude Sonnet Error pattern scan Interactive edit
🙋
HITL — Human In The Loop
Human oversight during automation
If a step fails and requires human judgement, an in-browser draggable overlay pauses the Playwright session and prompts the tester to Continue manually, Skip the step, or Stop the run entirely. After the human acts, execution resumes — combining automation speed with human accuracy.
Pause Gate Browser inject Continue/Skip/Stop
📚
Execution Learning
System gets smarter with every run
Every successful and failed test run is captured, vectorised, and stored. The RAG retrieval pipeline then includes these "execution patterns" alongside raw metadata. Over time, the AI learns which locators work, which field orders matter, and which patterns to avoid — improving future generation accuracy automatically.
Feedback loop Pattern vectors Continuous improvement
